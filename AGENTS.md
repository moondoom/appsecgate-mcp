# AGENTS.md — AppSecGate MCP

## Project
AppSecGate MCP — security scanner. Python 3.12+, FastMCP, Pydantic 2.7, SQLite.
Сервер находит, хранит, трекает и верифицирует находки. Фикс генерирует и
применяет AI-агент своей LLM — сервер этого не делает.

## Production dependencies
Только три: `mcp`, `pydantic`, `PyYAML`. Новые production-зависимости
запрещены. Dev-зависимости (`pytest`, `ruff`) — не трогать без причины.

## Invariants (нарушать нельзя)
1. Проект монтируется `:ro` — сервер НЕ пишет файлы проекта. Никогда.
2. `network_mode: none` — никаких HTTP-вызовов из сервера. Ни в Фазе 1,
   ни в коде, который «когда-нибудь понадобится в Фазе 2».
3. Ноль LLM-вызовов на сервере. Никаких `openai`, `anthropic`, `ollama`,
   `httpx` для LLM. Контекст-пакет — это данные, а не промпт.
4. Redaction секретов ДО записи в БД. Не «при отдаче», а при записи.
5. `query_findings_db` — только `SELECT` по публичным views. Никаких
   `UPDATE`/`DELETE`/`ATTACH`/`PRAGMA`.
6. `project_id` фиксируется при `SessionState.initialize()`. Смена
   `project_path` в одной сессии → ошибка, не warning.

## No migration
Продукт не релизился. Миграции не нужны. Схема SQLite создаётся с нуля
в финальном виде. Если существующие таблицы не соответствуют новой
схеме — пересоздаются, не мигрируют.

## Build / Test
- `make check` — ruff + pytest (обязательно зелёный перед PR)
- `make format` - запускать а не пробовать исправить переносы в ручную
- 186 существующих тестов должны остаться зелёными. Если тест падает —
  остановиться, разобраться, не «обновлять тест под код».

## Rules
- Один PR = один этап из роадмапа спеки (§8).
- Не менять сигнатуры существующих MCP-тулов без явного указания.
- Не удалять таблицы `shown_findings`, `suppressions`, `feedback`.
- Не добавлять поля в `Config` без явного указания — `update_config`
  валидирует схему, лишнее поле сломает валидацию.
- Перед коммитом — `make check`.

## Что НЕ делать
- Не вызывать `subprocess` с `shell=True`.
- Не писать в `/tmp` файлы > 10 МБ (tmpfs 100M).
- Не логировать промпты или сырые секреты.
